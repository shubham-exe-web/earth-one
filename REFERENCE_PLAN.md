# Earth One independent-reference plan

1. Discover Landsat 8/9 Collection 2 Level-2 scenes covering HAMFO-01 for the target dates.
2. Rank by temporal proximity and cloud cover.
3. Retrieve only required AOI assets.
4. Apply Landsat QA_PIXEL and relevant QA masks.
5. Compute independent NDVI/NDMI (or use the USGS-derived spectral-index assets where available).
6. Align to the Earth One comparison grid.
7. Compare direction and magnitude of change against Sentinel-2.
8. Record agreement, disagreement and effective validation coverage.
9. Promote evidence only if the independent-reference gate passes.
