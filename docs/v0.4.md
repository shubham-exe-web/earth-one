# Earth One v0.4 — Real Sentinel-2 Analysis-Ready Product

## Status

v0.4 is the first version that performs an actual Earth-observation raster
transformation rather than only defining a preprocessing contract.

## Implemented Sentinel-2 L2A pipeline

```text
SAFE / ZIP
   ↓
locate B02 B03 B04 B08
   ↓
locate SCL
   ↓
read 10 m bands
   ↓
convert scaled DN → reflectance
   ↓
common CRS/grid
   ↓
resample spectral bands
   ↓
nearest-neighbour SCL resampling
   ↓
mask cloud / shadow / snow / invalid classes
   ↓
4-band float32 GeoTIFF
   ↓
provenance metadata
```

The Sentinel-2 L2A collection is officially identified as `sentinel-2-l2a` in
the current Copernicus Data Space documentation. Its processing API supports
cloud-coverage filtering and exposes the collection's available bands and
processing options. citeturn0search3

Raster reprojection is implemented using Rasterio's geospatial reprojection
functions. Rasterio documents `calculate_default_transform()` for calculating
the destination grid and `reproject()` for transferring raster values between
CRSs. citeturn0search0turn0search1

## Output bands

The v0.4 analysis-ready product contains:

- B02: blue
- B03: green
- B04: red
- B08: near-infrared

All are harmonized to the same grid and stored as float32 reflectance.

## Quality mask

The default SCL mask excludes:

- no data
- saturated/defective
- cloud shadow
- medium-probability cloud
- high-probability cloud
- thin cirrus
- snow/ice

The mask is intentionally conservative because later carbon and change-detection
modules should not interpret cloud contamination as ecological change.

## Important scientific boundary

v0.4 is **not yet a carbon estimator**.

It creates a reliable input product for the next scientific layer.

The first downstream quantities can be:

- NDVI
- NDMI
- vegetation change
- burn/change candidate masks

but carbon should not be inferred until the model is calibrated/validated against
appropriate biomass/carbon reference data.

## Target CRS

If no target CRS is supplied, v0.4 preserves the source CRS.

This avoids silently treating a 10 m spatial resolution as 10 degrees when using a
geographic CRS.

For a production AOI, Earth One should select an appropriate projected CRS or
use a common project grid.

## Reproducibility

Every output GeoTIFF records:

- Earth One processor version
- input path
- product type
- reflectance scaling
- mask classes
- target resolution

The next version should additionally persist the original STAC item ID directly
inside the processing record.
