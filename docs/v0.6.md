# Earth One v0.6 — Multimodal Disturbance Evidence

## Objective

v0.6 connects optical and SAR observations.

The scientific progression is now:

```text
Sentinel-2
   ↓
NDVI
   ↓
temporal change
        +
Sentinel-1
   ↓
calibrated backscatter
   ↓
orthorectification / terrain-aware processing
        ↓
OPTICAL + SAR FEATURE STACK
        ↓
DISTURBANCE EVIDENCE
```

## Sentinel-1 implementation choice

Earth One does **not** implement a homemade SAR calibration chain in v0.6.

Instead, it calls the current Copernicus Data Space Sentinel Hub Process API and
requests a defined Sentinel-1 GRD processing configuration.

The official CDSE documentation describes Sentinel-1 GRD processing options
including beta0, sigma0 ellipsoid, gamma0 ellipsoid and gamma0 terrain, plus
orthorectification, DEM selection and optional speckle filtering. citeturn0search0turn0search1

For v0.6 the default is:

- VV + VH
- gamma0 terrain
- orthorectification
- Copernicus DEM 30 m

This is a deliberate scientific choice for land-change analysis, not a claim that
this configuration is optimal for every future Earth One task.

## Temporal optical composite

v0.6 adds a pixel-wise median composite for already harmonized observations.

This provides a more stable temporal representation than selecting one arbitrary
scene, but it does not magically remove phenology or atmospheric effects.

The temporal window must therefore be scientifically designed.

## Optical + SAR feature stack

The current stack is:

1. NDVI
2. VV
3. VH

Sentinel-1 is spatially reprojected onto the Sentinel-2/NDVI reference grid.

The stack builder performs spatial harmonization only. It does not perform SAR
calibration itself.

## Disturbance evidence

The current score is intentionally called:

**disturbance evidence score**

not:

**probability of deforestation**
or
**wildfire probability**

That distinction protects the scientific integrity of the project.

The score currently measures the strength of the observed index-change signal.
The next AI layer will combine optical, SAR, temporal and contextual evidence.

## Why this matters

With v0.5 we had:

`vegetation changed`

With v0.6 we can begin asking:

`did the optical signal change while radar structure also changed?`

That is the first foundation for multimodal disturbance attribution.

## Next: v0.7

v0.7 should introduce the first AI/model-routing layer:

```text
Optical + SAR + temporal features
            ↓
      feature validation
            ↓
       model router
            ↓
  disturbance classification
            ↓
forest loss / wildfire / harvest /
drought stress / restoration / unknown
```

The classifier must be trained and evaluated against labeled reference data.
Earth One should never convert an unvalidated heuristic directly into a scientific
claim.
