# Earth One v0.2 — Download and Processing Handoff

## What changed

v0.1 established:

`STAC discovery → state database → acquisition manifest`

v0.2 adds:

`authenticated download → atomic file write → SHA-256 provenance → processing handoff`

## Authentication

CDSE Sentinel Hub uses OAuth2 client credentials. Earth One keeps credentials
outside source code:

```text
CDSE_CLIENT_ID
CDSE_CLIENT_SECRET
```

The token provider caches the token until it is close to expiry instead of
requesting a new token for every data request.

## Download safety

Downloads are written to:

`filename.part`

and renamed only after a successful HTTP response and completed stream.

This protects the state machine from partially downloaded products.

## Scientific boundary

The download module does not perform scientific processing.

The next module must turn downloaded products into standardized analysis-ready
data with explicit:

- CRS
- spatial resolution
- band/polarization identity
- nodata
- quality masks
- temporal metadata
- source lineage
- processor version

## Why this separation matters

If a carbon estimate is challenged later, Earth One must be able to reconstruct:

**which observation → which preprocessing → which model → which parameters → which output**

That provenance chain is a core research requirement, not merely a software feature.
