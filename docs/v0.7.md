# Earth One v0.7 — AI Model Routing and Disturbance Classification

## Objective

v0.7 introduces the first AI decision layer.

The pipeline becomes:

```text
OPTICAL + SAR + TEMPORAL EVIDENCE
             ↓
        FEATURE CHECK
             ↓
        MODEL ROUTER
             ↓
   ┌───────────────────────────┐
   │ multimodal classifier     │
   │ optical temporal model    │
   │ SAR change model          │
   │ insufficient evidence     │
   └───────────────────────────┘
             ↓
        AI CLASSIFIER
             ↓
     CLASS + CONFIDENCE
```

## Model router

The router is deterministic in v0.7.

It chooses a model family according to the evidence available:

- optical + SAR + context
- optical + SAR
- optical temporal
- SAR change
- insufficient evidence

This is intentionally not a learned meta-router yet.

The future router should choose models according to validated performance for
the specific task, geography, season, sensor availability, and uncertainty.

## Baseline classifier

v0.7 provides a Random Forest baseline over:

- NDVI
- ΔNDVI
- VV
- VH

Training requires a spatially aligned integer label raster.

The baseline uses class balancing and stratified train/test splitting.

### Important limitation

A random pixel split can overestimate generalization because neighboring pixels
are spatially correlated.

Therefore the reported accuracy is a **development metric**, not final evidence
of scientific generalization.

The next validation system should use:

- spatial holdout
- temporal holdout
- independent reference data
- confusion matrix
- per-class precision/recall/F1
- calibration
- uncertainty
- area-adjusted accuracy where appropriate

## Confidence

The inference output includes maximum class probability from the Random Forest.

Earth One labels this:

**model confidence**

and explicitly does not call it a calibrated probability.

Calibration belongs in the uncertainty/validation layer.

## Scientific classes

v0.7 intentionally does not hard-code claims such as:

- wildfire
- deforestation
- harvest
- drought
- restoration

into numerical class IDs.

The label raster defines the class system.

This prevents the software from quietly imposing a scientific taxonomy before
the study design establishes it.

## Research significance

v0.7 creates the first bridge between:

**multimodal Earth observation**

and

**automated scientific interpretation.**

The system can now:

1. inspect evidence availability,
2. choose an appropriate model family,
3. train a baseline classifier,
4. generate class predictions,
5. generate confidence,
6. apply a development quality gate.

## Next: v0.8

v0.8 should focus on **real validation and uncertainty** rather than immediately
adding another model.

Target:

```text
prediction
   ↓
spatial validation
   ↓
temporal validation
   ↓
independent reference
   ↓
probability calibration
   ↓
uncertainty map
   ↓
scientifically defensible event product
```

Only after this should Earth One move into biomass/carbon estimation.
