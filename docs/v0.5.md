# Earth One v0.5 — First Environmental Signal

## Objective

v0.5 turns the v0.4 analysis-ready Sentinel-2 product into a measurable
vegetation signal and adds the first temporal change detector.

The pipeline is now:

```text
Sentinel-2 L2A
  ↓
analysis-ready B02/B03/B04/B08
  ↓
NDVI
  ↓
baseline vs comparison
  ↓
ΔNDVI
  ↓
change candidate
```

## Implemented

### NDVI

NDVI is calculated from the red and near-infrared bands:

`NDVI = (NIR - Red) / (NIR + Red)`

The result is stored as a single-band float32 GeoTIFF with provenance tags.

### Temporal change

For two aligned NDVI products:

`ΔNDVI = NDVI_comparison - NDVI_baseline`

A configurable absolute threshold creates a change candidate mask.

The threshold is **not treated as a universal scientific constant**. It must
eventually be calibrated against seasonality, phenology, preprocessing noise,
land-cover type, and the target disturbance.

## Important limitation

The current v0.4 product has no SWIR band, so v0.5 does not pretend to calculate
NDMI. A future expanded Sentinel-2 product must include SWIR before NDMI is
implemented.

## Scientific meaning

v0.5 does not classify every detected change as deforestation, wildfire, harvest,
drought, or restoration.

It only establishes:

**observable spectral change → candidate disturbance**

Attribution requires additional temporal, spatial, SAR, weather, land-cover,
and eventually AI evidence.

That distinction is essential for a defensible scientific system.

## Next

v0.6 should add:

- Sentinel-2 temporal compositing
- Sentinel-1 preprocessing
- optical + SAR co-registration
- disturbance feature stack
- candidate-event scoring

Then Earth One can begin distinguishing different causes of observed change.
