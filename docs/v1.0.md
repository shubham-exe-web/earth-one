# Earth One v1.0 — Autonomous Observation Loop

## Purpose

v1.0 is the first release that closes the loop from repeated Earth observation
to a persistent disturbance history.

```text
ACQUIRE
   ↓
PREPROCESS
   ↓
DETECT
   ↓
CLASSIFY
   ↓
VALIDATE
   ↓
SEGMENT
   ↓
TRACK THROUGH TIME
   ↓
BIOMASS / CARBON BRIDGE
   ↓
UNCERTAINTY
   ↓
RESEARCH-READY OBSERVATION
```

## Persistent event tracking

v1.0 links v0.9 event polygons across observation dates.

Two events can be linked using:

- polygon intersection-over-union (IoU)
- centroid distance

The matching thresholds are configurable.

The result is a persistent Earth One track ID such as:

`EO1-000001`

A track stores:

- first observation
- last observation
- number of observations
- cumulative observed area
- peak observed area
- maximum absolute index change
- mean evidence score
- individual observations and geometries

### Important limitation

The v1.0 tracker is deterministic.

It does not yet fully solve complex:

- split events
- merge events
- occlusion
- intermittent disappearance
- reappearance after long gaps

Those should become a dedicated tracking research problem rather than being
silently hidden inside a heuristic.

## Biomass/carbon bridge

v1.0 introduces a strict carbon-accounting interface.

It accepts **supplied, separately validated biomass rasters** for before and after
an event and computes:

`biomass change = biomass after - biomass before`

and:

`carbon change = biomass change × carbon fraction`

The default carbon fraction is configurable.

This is intentionally not an NDVI-to-carbon shortcut.

The system records carbon as unavailable when a validated biomass layer has not
been supplied.

## Uncertainty

v1.0 preserves the uncertainty layer introduced in v0.8 and allows an optional
biomass uncertainty fraction to be propagated into the event-level carbon
result.

This is a first operational bridge, not a complete uncertainty propagation
framework.

A production carbon product should combine uncertainty from:

- event boundary
- classification
- biomass estimation
- carbon fraction
- temporal mismatch
- reference data
- model calibration

## Research-ready observation

v1.0 can package persistent event tracks and optional carbon results into a
versioned observation object.

This is the first data structure suitable for downstream research-paper
generation.

## What v1.0 means scientifically

Earth One can now represent a chain such as:

```text
Observation A
   ↓
disturbance detected
   ↓
Event EO1-000127
   ↓
Observation B
   ↓
same event persists / evolves
   ↓
validated biomass difference
   ↓
carbon-change estimate
   ↓
uncertainty
```

It still does **not** mean every carbon estimate is automatically scientifically
valid. The validity depends on the reference biomass product, calibration,
validation design and uncertainty model.

## Next research layer

The software foundation is now mature enough to split into independent research
tracks:

1. **Automated disturbance detection**
2. **Multimodal event classification**
3. **Persistent event tracking**
4. **Biomass estimation**
5. **Carbon accounting**
6. **Uncertainty propagation**
7. **Autonomous research observation generation**

That separation is important because each track can become a distinct scientific
contribution rather than forcing everything into one oversized paper.
